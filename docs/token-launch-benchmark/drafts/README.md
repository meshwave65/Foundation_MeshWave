## Guardrails de redação
1. Não declarar preço, captação, volume, listagem, liquidez, retorno ou data sem decisão e fonte confirmadas.
2. Separar oferta primária (captação) do trading secundário (volume).
3. Separar preço de venda, preço de abertura e máxima intraday.
4. Não sugerir rendimento garantido, valorização, segurança absoluta ou listagem assegurada.
5. Distinguir UMS e MWN conforme a arquitetura MeshWave; não usar MWC como nome atual, salvo referência histórica.
6. Cada dado publicado precisa de fonte, data de corte e unidade.
7. Campos [A VALIDAR] permanecem em branco até decisão interna.
