# Relatório parcial 01 — Escopo e seleção inicial dos casos

**Data de reconstrução:** 2026-11-05  
**Natureza:** relatório retrospectivo, reconstruído a partir dos arquivos já persistidos e do contexto recuperável da conversa.  
**Status:** registrado; seleção inicial de casos documentada.

## 1. Objetivo definido

Criar no repositório Foundation_MeshWave uma base de documentação sobre lançamentos de tokens de terceiros, para estudar estruturas, resultados e métricas e, posteriormente, derivar drafts de comunicação para MWN.

O benchmark não é um estudo do preço de venda próprio de MWN, nem aprovação de seus parâmetros econômicos. O foco são lançamentos externos: mecanismo de lançamento, preço ou referência inicial, captação quando aplicável, volume secundário, liquidez, distribuição e desempenho pós-TGE.

## 2. Escopo de trabalho estabelecido

- Manter estudos de casos-modelo com links e ressalvas.
- Diferenciar ICO/IDO/venda, airdrop, TGE, LBP e lançamento via pool/DEX.
- Usar os dados como evidência comparativa, não como previsão de resultado para MWN.
- Não completar informações ausentes por inferência.
- Separar benchmark de terceiros de drafts internos de comunicação MWN.
- Não tratar nomes antigos do ativo como denominação atual: MWN é a designação atual; MWC pode aparecer somente como referência histórica.

## 3. Amostra inicial persistida

O benchmark foi estruturado com estes casos:

| Caso | Mecanismo ou evento | Por que foi incluído |
|---|---|---|
| MON — Monad | Venda pública + distribuição | Distinguir preço de venda, proceeds e mercado secundário |
| PUMP — Pump.fun | Venda pública | Grande captação primária, para não confundir com volume de trading |
| BERA — Berachain | Airdrop + CEX | Volume e valuation de lançamento reportados |
| LINEA | TGE + listagem | Divergência entre preço e volume reportados |
| ASTER | Lançamento DEX | Referências conflitantes de abertura e volumes spot/derivativos |
| JUP — Jupiter | Airdrop + pool DEX | Separar token de atividade do agregador/protocolo |
| HYPE — Hyperliquid | Airdrop | Caso de distribuição e evolução de preço |
| KAITO | TGE/distribuição | Caso com dados inaugurais ainda incompletos |
| HUMA — Huma Finance | Launchpool + listagem | Dados reportados de abertura e volume D1 |
| MET — Meteora | LGE + distribuição em LP | Distinguir preço de pool/LGE de mercado consolidado |

## 4. Estrutura documental criada

- README geral com critérios de leitura e lista dos casos.
- Um documento por caso em `cases/`.
- Diretório `drafts/` para materiais internos MWN.
- Relatórios de pesquisa e reconciliação em documentos separados.

Os casos foram mantidos com ressalvas explícitas: alguns dados vieram de cobertura secundária e precisam de validação antes de reutilização pública.

## 5. Conclusão da etapa

Foi estabelecida uma amostra inicial útil e um esqueleto documental persistido. A amostra é heterogênea por design: inclui vendas primárias, airdrops, pools e listagens. Portanto, não pode ser comparada usando um único número de “preço de lançamento” ou “volume”.

## 6. Próxima etapa que decorreu deste trabalho

Expandir a evidência para mais lançamentos de 2024–2026, incluindo casos que permitam observar diferentes mecanismos e riscos. A expansão deverá permanecer como conjunto complementar, sem apagar a seleção inicial.
