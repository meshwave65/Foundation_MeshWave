## Estado e cautela

Os documentos sobre MWN, mercado próprio e governança são preliminares. A documentação não comprova que uma exchange própria, matching engine, mercado secundário ou prioridade técnica de ordens já estejam implementados. As aquisições primárias devem ser distinguidas de negociações secundárias. Os documentos não constituem oferta de investimento, promessa de liquidez ou valorização, nem parecer jurídico.
